# TRENDFIX Salon and Spa — Bagumbong Branch

A responsive four-page salon website built with semantic HTML, CSS, and vanilla JavaScript. Open `index.html` directly in a browser or serve this folder with any static web server. The existing `imgs/` directory contains the supplied business photography and branding reference.

The portfolio lightbox and mobile navigation run locally in the browser. The location map is an embedded Google Maps search for the supplied address; opening directions launches Google Maps.
